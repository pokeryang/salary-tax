计算方法说明

① 社保公积金
社保 = min(月薪, 社保上限) × 10.5%（养老8% + 医疗2% + 失业0.5%）
公积金 = min(月薪, 公积金上限) × 12%（月缴存额取整到元）
· 2021年：社保上限19783、公积金上限32077。社保公积金总计5926.22（月薪26000未达公积金上限，实际约5197.22）
· 2022年：社保上限22311、公积金上限36675。社保公积金总计6743.65（月薪29500未达公积金上限，实际约5245.22）
· 2023年：社保上限24060、公积金上限38390。社保公积金总计7133.30（月薪36000未达公积金上限，实际约6949.66）
· 2024年：社保上限24930、公积金上限39530。社保公积金总计7361.65
· 2025年：社保上限25299、公积金上限40694。社保公积金总计7539.40
· 2026年：社保基数25299未变（养老2023.92 + 医疗505.98 + 失业126.50 = 2656.40）、公积金基数上调至42150（×12% = 5058.00）。社保公积金总计7714.40，自归属2026年7月（8月发放）起生效
每年7月上调，公积金基数调整体现在下月发放的工资里

② 发放口径（关键）：工资滞后一个月发放
表中「月份」是归属月，实际发放在次月——归属7月的工资8月发。个税和社保按发放月计入税年与累计：
· 累计月数 = 发放月序号，不是归属月序号。归属7月是当年第8笔发放，累计减除费用为 5000×8 = 40000
· 每年归属12月的工资在次年1月发放，计入次年累计的第1笔。所以一个税年的累计口径 = 归属上年12月 + 归属本年1～11月，归属12月的税记在次年
· 长期现金激励、十三薪随所属月工资一同发放，归属月与当月工资一致
· 校验锚点（归属2026年7月工资条）：累计收入635035 = 86400（归属2025-12，含十三薪43000）+ 433576（归属2026年1～6月）+ 115059（归属2026-07）；累计社保公积金60490.20 = 7539.40×7 + 7714.40；累计已缴107443.44

③ 工资个税（累计预扣法）
本笔税额 = （累计收入 − 5000×发放月序号 − 累计社保公积金）× 预扣率 − 速算扣除数 − 前几笔累计已扣
档位查的是累计应纳税所得额（上式括号内的值），不是累计收入：
· 累计应纳税所得额≤36000→3%(0)
· ≤144000→10%(2520)
· ≤300000→20%(16920)
· ≤420000→25%(31920)
· ≤660000→30%(52920)
· ≤960000→35%(85920)
· 其余→45%(181920)
每年1月发放的那一笔起累计额归零
举例（假设每月工资50000、每月社保公积金7539.40、无专项附加扣除）：
· 第1笔（1月发，归属上年12月）：50000 − 5000×1 − 7539.40 = 37460.60，落10%档 → 37460.60×10% − 2520 = 1226.06，本笔扣1226.06。
· 第2笔（2月发，归属1月）：累计100000 − 10000 − 15078.80 = 74921.20，仍10%档 → 累计税74921.20×10% − 2520 = 4972.12，减已扣1226.06，本笔扣3746.06。
· 第4笔（4月发，归属3月）：累计200000 − 20000 − 30157.60 = 149842.40，跨入20%档 → 149842.40×20% − 16920 = 13048.48，减前3笔累计已扣8718.18，本笔扣4330.30。

④ 年终奖 + 特殊递延（全年一次性奖金单独计税）
年终奖与特殊递延激励合并为一个基数，不并入当月工资
· 第一步：（年终奖 + 特殊递延）÷12 商数定档 预扣率、速算扣除数
· 第二步：奖金税 = 合并基数 × 适用税率 − 速算扣除数（注意：税率乘的是「合并基数全额」，不是除以12后的商数）。
举例：
· 第一步：26年4月奖金合并基数 = 360000 + 204150 = 564150；564150÷12 = 47012.50，落在 35000~55000 档 → 税率30%、速算扣除数4410；
· 第二步：奖金税 = 564150×30% − 4410 = 164835
· 注意：单独计税额度一个纳税年度只能用1次，用掉后同年其他一次性收入（十三薪、长期现金激励等）必须并入综合所得。现行单独计税政策执行至2027年12月31日，2028年起若未延续须并入综合所得——表中2028年4月仍按单独计税测算，届时需复核。

⑤「年度奖金」是独立的一张税单（归属2024年4月工资条实证）
年终奖、其他现金激励、十三薪可能被整包合并进「年度奖金」一张单，按全年一次性奖金单独计税，完全不进工资累计：
· 归属2024-04：年终奖250000 + 其他现金激励165000 + 十三薪全额36000 = 报税收入451000；451000÷12 = 37583.33 落30%档 → 451000×30% − 4410 = 130890；进卡 422200 − 130890 = 291310
· 十三薪已在归属2024-01预发80%（28800）现金，但不计入工资累计收入，其税基留到4月的奖金单里一并计算
· 同月工资侧独立走累计预扣：累计收入184001.68 − 25000 − 37301.82 = 121699.86 → 10%档 → 累计税9649.99 − 已缴6823.32 = 本期2826.67；进卡 40400 − 7133.30 − 2826.67 = 30440.03；两张单合计进卡321750.03
· 表内填法：归属2024-01 的 28800 记在「特殊递延」列（当月不计税、bonus_tax=0），归属2024-04 的年终奖250000 + 特殊递延172200（= 现金激励165000 + 十三薪尾款7200）= 当月现金422200，奖金个税填实际的130890。此行奖金税≠用现金列422200套公式算出的122250，因为税基451000还含1月已预发的28800——这是历史特例，不是填错
· 2025年起口径变化：现金激励改记入「特殊递延」与年终奖合并单独计税（归属2025-04 = 200000+165000→88590，归属2026-04 = 360000+204150→164835，均已实测吻合）；十三薪改为全额随归属12月工资并入综合所得（归属2024-12 = 40000、归属2025-12 = 43000 实测）

⑥ 预估行的填充规则（由实际工资条反推）
· 月薪 base：涨薪一律在归属4月生效（2022/2023/2024/2025/2026 连续5年命中）；预估按 归属2027-04 起 55000
· 饭贴：380/月，取近24个实际月均值384.17（约20元×工作日，实际在280~460之间波动）
· 十三薪：每年归属12月发放、金额 = 当月 base，并入综合所得；因滞后一个月发放，它是次年累计的第1笔，所以归属12月税负很低
· 长期现金激励（本BU）：归属 1/4/7/10 月各一次，并入综合所得（归属2026-07实测65659 = 13543 + 14616 + 37500）
· 社保公积金：每年归属7月上浮 2.4%（近两年实测 +2.41% / +2.32%）→ 归属2027-07起7899.55、2028-07起8089.14、2029-07起8283.28
· 专项附加扣除：历史实测 2022年累计4500、2023年累计10500（均为住房租金，中途停报），2024/2025/2026 三年均为 0。预估行按 0 填。如申报婴幼儿照护2000/月，30%档每年可少缴约7200
· 实际行不参与重算：累计链走到实际月时，直接续接工资条上的实缴税额，只对预估月套用上述公式

⑦ 各年度「年终奖」税基口径（6张工资条反推）
公式本身逐年没变，一直是标准的全年一次性奖金单独计税：合并基数÷12 定档 → 税 = 合并基数全额 × 税率 − 速算扣除数。
真正变的是「往这个基数里装什么」，共三个阶段：
· 2019～2021：只装年终奖。2019-01 10000→300；2019-07 30000→900；2020-02 14000→420；2021-02 66000→6390（66000/12=5500 落10%档 → 66000×10%−210）
· 2022～2024：年终奖 + 十三薪全额（含春节前已预发的80%）。已预发部分当月只发现金、不进工资累计收入，税基留到次年4月的奖金单里一起算：
  — 归属2022-04：123000 + 尾款4160 + 已预发16640 = 143800；143800/12=11983.33 落10%档 → 143800×10%−210 = 14170
  — 归属2023-04：190000 + 尾款5900 + 已预发23600 = 219500；219500/12=18291.67 落20%档 → 219500×20%−1410 = 42490
  — 归属2024-04：250000 + 现金激励165000 + 十三薪36000（尾款7200＋已预发28800） = 451000；451000/12=37583.33 落30%档 → 451000×30%−4410 = 130890
· 2025年起：年终奖 + 长期现金激励；十三薪改为全额随归属12月工资并入综合所得，不再进奖金单：
  — 归属2025-04：200000 + 165000 = 365000；365000/12=30416.67 落25%档 → 365000×25%−2660 = 88590
  — 归属2026-04：360000 + 204150 = 564150；564150/12=47012.50 落30%档 → 564150×30%−4410 = 164835
表内填法：奖金单里「已预发的十三薪」记在发钱那个月的「特殊递延」列（当月 bonus_tax = 0），4月奖金单只填当月实际到账的现金与实缴奖金税。所以 2022/2023/2024 三年的4月，奖金个税 ≠ 用本行现金列套公式的结果，差的正是上一年12月已预发的那笔——这是口径特例，不是填错。

⑧ 税后减项（商保 / 月饼 / 年货卡 合并计税扣回）
公司发的实物福利与商业保险要并入当月工资计税，做法是：先在「税前加项」加一笔计税金额，个税照常扣，再在税后把对应金额扣回，等于福利本身不给现金、只承担税。
· 归属2023-11：税前加项1572.25（月饼148.42 + 商保1423.83），税后减项1257.80（月饼118.74 + 商保1139.06），实缴个税5212.52，工资进卡24592.27
· 归属2025-11：税前加项2972.08（商保、年货卡合并计税反推），税后减项1931.85（商保1811.85 + 年货卡120），实缴个税92692.44，工资进卡216420.39
本表没有「税后减项」列，为了让税前合计与到手两头都对得上，这两个月把税后扣回并进了「综合个税」列（= 实缴个税 + 税后扣回），行内备注已注明真实的实缴个税金额。
